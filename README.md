# Chocolate Sales Database Using PL/SQL

This project focuses on developing a structured relational database for chocolate sales data, designed to support efficient data management and analysis using PL/SQL. The system organizes core business data across related tables including calendar, customers, products, stores, and sales. Each table captures key attributes such as transaction details, product information, customer data, and store locations while maintaining strong relational integrity.

The dataset, sourced from Kaggle, contains large-scale sales data and was modified to meet third normal form (3NF) standards. This ensures minimal redundancy and consistent data relationships, creating a reliable foundation for querying and analysis.

In addition to database design, PL/SQL is used to implement business logic and automate operations. The project includes the use of loops, cursors, conditional logic, procedures, functions, exception handling, and packages. These components allow for dynamic data retrieval, revenue calculations, classification of sales, and controlled data updates.

To safely demonstrate update operations, a copy of the sales table is used to prevent modification of the original dataset. This approach allows for realistic simulation of business processes such as applying and reversing discounts.

Overall, this project demonstrates how PL/SQL can be used to enhance database functionality by combining structured data design with procedural logic. The result is a scalable and organized system for analyzing chocolate sales activity.
